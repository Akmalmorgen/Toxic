# 𐌽ꤕ𐌗ተ — анонимный Telegram-бот

Бот для **анонимного общения**: вопросы и валентинки по личной ссылке, чат-рулетка по полу, 18+ рулетка с поиском по возрасту, магазин с коинами и VIP, рефералы с наградами и мультиязычность (🇷🇺 / 🇺🇿 / 🇬🇧).

Написан на [aiogram 3](https://docs.aiogram.dev/), работает на **PostgreSQL (Neon)** или **SQLite**. Запускается на Render, Railway, VPS или в Docker.

---

## ✨ Возможности

| Раздел | Что умеет |
|---|---|
| 🔗 **Моя ссылка** | Личная ссылка `t.me/bot?start=КОД`. Люди пишут тебе анонимно: ❓ вопрос или 💌 валентинка. Кнопка «Поделиться» с превью-карточкой бота. Менять можно раз в неделю (VIP — без ограничений). |
| 🎲 **Чат-рулетка** | Случайный собеседник по полу. Управление снизу: «Далее» / «Стоп». Приоритет для VIP. |
| 👁 **Узнать кто** | Раскрытие отправителя анонимки за **Telegram Stars** ⭐. Админ/модер — бесплатно. |
| 👥 **Пригласить** | Рефералы: коины за друзей + **бесплатный VIP** и **модерка на неделю** за приглашённых. Настройки наград редактируются админом. Топ пригласивших. |
| 🛒 **Магазин** | Покупка коинов, VIP, модерки за коины. Цены с VIP-скидкой −20%. Админ/модер — 0. |
| 🎁 **Подарить коины** | Перевод коинов другу по ID или @username. |
| 🔞 **18+ зона** | Отдельная рулетка с поиском по возрастным диапазонам, 18+ магазин (покупка доступа за коины), подарок 18+ другу. Верификация возраста через фото документа. |
| 🛡 **Модерация / Админка** | Жалобы, баны, рассылки (в т.ч. альбомами), обязательные каналы, статистика, выдача модерки/коинов/VIP по ID и массово, реклама, скрытые команды `/tg` и `/next`. |
| 🛡 **Анти-спам** | Блокировка ссылок, @юзернеймов, номеров и упоминаний соцсетей в анонимках и обычной рулетке. В 18+ чате фильтр отключён. |
| 🌐 **Языки** | Русский, узбекский, английский. Автоперенос эмодзи во все языки. |
| 💾 **Устойчивость** | Ретраи подключения к Neon, автоперезапуск поллинга, фоновая очистка БД, автоудаление мёртвых аккаунтов. |

## 🚀 Быстрый старт (локально)

```bash
git clone https://github.com/Akmalmorgen/Toxic.git
cd Toxic

cp .env.example .env          # впишите BOT_TOKEN и ADMIN_IDS
pip install -r requirements.txt
python main.py
```

Токен бота берётся у @BotFather, свой Telegram ID — у @userinfobot.

---

🔧 Переменные окружения

Переменная Обязательна Описание
BOT_TOKEN ✅ Токен бота от @BotFather
ADMIN_IDS ✅ ID администраторов через запятую: 123,456 (без пробелов)
DATABASE_URL ⚠️ рекомендуется Строка PostgreSQL (Neon). Без неё — SQLite, который стирается при перезапуске на облачных хостингах.
DB_PATH — Путь к SQLite-файлу (если нет DATABASE_URL). По умолчанию ./bot.db
PORT — Порт keep-alive HTTP. Render даёт автоматически.

---

☁️ Деплой на Render (бесплатно)

1. New → Web Service → подключи репозиторий.
2. Render прочитает render.yaml автоматически.
3. В Environment задай: BOT_TOKEN, ADMIN_IDS, DATABASE_URL.
4. Manual Deploy → Clear build cache & deploy.
5. Открой Logs — дождись строки 🚀 Бот запущен, поллинг...
6. Подключи UptimeRobot — пингуй URL каждые 5 минут, чтобы free-план не засыпал.

Railway / Heroku

Используется Procfile: web: python main.py. Задайте те же переменные.

Docker (VPS)

```bash
docker compose up -d --build
docker compose logs -f
```

Обычный VPS (systemd)

```bash
pip install -r requirements.txt
python main.py
```

Рекомендуется обернуть в systemd-сервис или screen/tmux.

🤖 Команды

Публичные

Команда Действие
/start Запуск, главное меню
/start <код> Открыть анонимку по чужой ссылке
/start ref_<код> Зайти по реферальной ссылке

Скрытые (только для персонала)

Команда Действие
/tg Мониторинг активных сессий рулетки (в т.ч. 18+) с кнопками бана
/next Написать любому пользователю от имени модератора

Полный разбор — в docs/COMMANDS.md.

---

🛡 Безопасность

· Никогда не коммитьте BOT_TOKEN — он в .gitignore, хранится только в переменных окружения.
· Если токен попал в публичный репо — немедленно отзовите у @BotFather (/mybots → API Token → Revoke).
· .env — только локально/на сервере. В git — только .env.example.
· Храни секреты на хостинге: Render → Environment, Railway → Variables.

---

📊 Технические детали

· Python: 3.12.11 (фикс в .python-version)
· БД: PostgreSQL (Neon Free — 512 МБ) или SQLite
· Срок хранения анонимок: 90 дней (автоочистка)
· Срок хранения сессий рулетки: 90 дней
· Обработанные жалобы: удаляются через 30 дней
· Активные данные: никогда не удаляются автоматически
